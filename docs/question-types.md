# 문항 유형 카탈로그

"문항이 다 비슷하다"를 해결하기 위한 발문(질문 문장) 목록이다.
새 문항을 쓸 때 이 목록에서 **의도적으로 골라 쓰면** 자연스럽게 유형이 흩어진다.

형식 규칙(선택지 5개, `answer` 1-based 등)은 [question-format.md](./question-format.md)를 참고할 것.

---

## 먼저 알아야 할 것: 다양성은 어디서 나오는가

`types/domain.ts`에 `type` 필드(`UNDERLINE_INTENT`, `BLANK_INFERENCE` 등)가 있지만,
**이 값은 화면 렌더링에 전혀 쓰이지 않는다.** 채워도 문항 모양은 달라지지 않는다.

실제로 문항 모양을 바꾸는 것은 다음 세 가지뿐이다.

| 요소 | 무엇을 바꾸는가 | 어디에 쓰는가 |
|---|---|---|
| **발문 문장** | 묻는 방식 자체 | `question` |
| **지문 마크업** | 지문에 밑줄·빈칸 표시가 생김 | `content` 안에 `㉠[밑줄:...]`, `[빈칸]` |
| **`<보기>` 상자** | 문항 아래 별도 자료 상자가 생김 | `context.content` |

지문 마크업과 `<보기>` 상자는 **시각적으로 확연히 다른 문항**을 만든다.
발문만 바꾸면 겉모습은 결국 비슷해 보이므로, 이 둘을 적극적으로 섞어야 한다.

---

## 현재 상태 확인 방법

```bash
node scripts/audit-assets.mjs --id=<관리자아이디> --pw=<비밀번호>
```

출력의 **📊 문항 유형 다양성** 항목을 본다.

- `상위 3개 패턴이 전체의 __%` → **50%를 넘으면 편중**된 것이다
- `<보기> 상자 사용 문항` → 10% 미만이면 거의 안 쓰고 있는 것
- `밑줄 마크업 있는 지문` / `빈칸 있는 지문` → 지문 자체가 밋밋한지 알 수 있다
- `완전히 똑같은 발문` → 그대로 복사된 문항

---

## 🔴 절대 규칙: 역량은 바꾸지 않는다

문항을 고칠 때 **`category`(평가 역량)는 절대 바꾸지 않는다.** 학년군별 역량 배분이
목표치에 맞춰져 있어서, 하나만 바꿔도 리포트의 역량별 점수가 왜곡된다.

형태를 바꾸더라도 **그 역량을 실제로 재는 문항**이어야 한다. 겉모습만 바꾸고
다른 역량을 재게 되면 역량표는 그대로인데 측정값이 엉뚱해진다.

실제로 겪은 실수:

> `비판적 이해` 문항을 `<보기>` 형으로 바꾸면서
> "대화 중 지문 내용과 다르게 말한 친구는?"으로 만들었다.
> → 이건 **지문에 적힌 사실과 대조**하는 것이라 `사실적 이해`다.
> 비판적 이해로 표시된 채 사실적 이해를 재고 있었다.

**역량별 판별 기준** — 문항을 만든 뒤 이걸로 되짚어 볼 것:

| 역량 | 학생이 실제로 하는 일 | 이러면 다른 역량이다 |
|---|---|---|
| 어휘력 | 문맥에서 낱말 뜻을 고른다 | 낱말이 아니라 문장 내용을 묻는다 → 사실적 |
| 사실적 이해 | 지문에 **쓰여 있는지** 확인한다 | 쓰여 있지 않은 걸 유추한다 → 추론적 |
| 추론적 이해 | 드러나지 않은 의미를 **유추**한다 | 지문에서 그대로 찾을 수 있다 → 사실적 |
| 구조적 이해 | 글의 **짜임·중심 내용**을 파악한다 | 세부 정보를 찾는다 → 사실적 |
| 비판적 이해 | 글쓴이의 **의도·관점·타당성을 평가**한다 | 내용이 맞는지 대조한다 → 사실적 |

## 학년군별 난이도 기준

같은 역량이라도 학년에 맞는 난이도로 내야 한다. `<보기>`를 쓸 때 특히 중요하다.

| 학년군 | `<보기>` 분량 | 소재 | 선택지 |
|---|---|---|---|
| 초등 저학년 | 1~2문장 | 교실·가정의 눈에 보이는 장면 | 짧은 구절, 한 줄 이내 |
| 초등 중학년 | 2~3문장 | 학교 생활 속 구체적 상황 | 한 문장 |
| 초등 고학년 | 3~4문장 | 사회적 사례, 짧은 자료·통계 | 한두 문장, 판단 근거 포함 |
| 중등 | 4~5문장 | 상반된 관점, 다른 글의 일부 | 두 문장 가능, 전제·논리 포함 |

**공통 원칙**
- `<보기>`는 지문을 읽지 않으면 풀 수 없어야 한다. 상식만으로 답이 나오면 문해력 문항이 아니다.
- `<보기>` 자체가 새로운 독해 부담이 되면 안 된다. 지문보다 쉬운 어휘로 쓴다.
- 저학년일수록 **한 가지만** 판단하게 한다. 여러 조건을 겹치면 난이도가 급격히 오른다.

## 역량별 발문 유형

각 역량마다 **서로 다른 묻는 방식**을 정리했다.
한 차시(지문 4개) 안에서 같은 유형을 두 번 이상 쓰지 않는 것을 목표로 한다.

### 어휘력

| 유형 | 발문 예시 | 필요한 장치 |
|---|---|---|
| 문맥 의미 | 밑줄 친 ㉠"실어 나릅니다"의 뜻으로 알맞은 것은? | `㉠[밑줄:...]` |
| 바꿔 쓰기 | ㉠과 바꾸어 쓸 수 있는 말은? | `㉠[밑줄:...]` |
| 반대말 | ㉠과 뜻이 반대인 낱말은? | `㉠[밑줄:...]` |
| 같은 쓰임 찾기 | ㉠이 쓰인 것과 같은 뜻으로 쓰인 문장은? | `㉠[밑줄:...]` |
| 낱말 채우기 | 빈칸에 들어갈 낱말로 알맞은 것은? | `[빈칸]` |
| 관용 표현 | "손을 놓다"와 뜻이 통하는 표현은? | — |
| 낱말 관계 | ㉠과 ㉡의 관계와 같은 것은? | 마커 2개 |

### 사실적 이해

| 유형 | 발문 예시 | 필요한 장치 |
|---|---|---|
| 내용 확인 | 이 글의 내용과 일치하는 것은? | — |
| 부정 확인 | 이 글의 내용과 **일치하지 않는** 것은? | — |
| 조건 찾기 | 이 글에 따르면 씨앗이 싹트기 위해 필요한 것은? | — |
| 대상 특징 | 글쓴이가 소개한 ○○의 특징으로 알맞은 것은? | — |
| 순서 배열 | 다음 과정을 일어난 순서대로 바르게 나열한 것은? | — |
| 확인 불가 | 이 글을 읽고 **알 수 없는** 것은? | — |
| 자료 대조 | `<보기>`의 내용 중 이 글에서 확인할 수 있는 것은? | `<보기>` |

### 추론적 이해

| 유형 | 발문 예시 | 필요한 장치 |
|---|---|---|
| 빈칸 추론 | `[빈칸]`에 들어갈 말로 가장 알맞은 것은? | `[빈칸]` |
| 이어질 내용 | 이 글 뒤에 이어질 내용으로 알맞은 것은? | — |
| 원인 추론 | ○○가 그렇게 행동한 까닭으로 알맞은 것은? | — |
| 심정 추론 | ㉠에서 인물의 마음으로 알맞은 것은? | `㉠[문장밑줄:...]` |
| 생략된 전제 | 글쓴이가 당연하게 여기고 있는 것은? | — |
| 사례 적용 | 이 글의 내용을 바르게 적용한 사례는? | `<보기>` |
| 결과 예측 | 만약 ○○하지 않는다면 일어날 일은? | — |

### 구조적 이해

| 유형 | 발문 예시 | 필요한 장치 |
|---|---|---|
| 중심 내용 | 이 글의 중심 내용으로 알맞은 것은? | — |
| 제목 붙이기 | 이 글의 제목으로 가장 알맞은 것은? | — |
| 문단 역할 | ㉠문단이 하는 역할로 알맞은 것은? | 문단 앞 마커 |
| 전개 방식 | 이 글의 짜임을 바르게 설명한 것은? | — |
| 문단 요약 | 2문단을 한 문장으로 요약한 것은? | — |
| 문장 넣기 | `<보기>`의 문장이 들어가기에 알맞은 곳은? | `<보기>` + 지문에 ㉠~㉣ |
| 흐름 벗어남 | 글의 흐름에서 벗어난 문장은? | 지문에 마커 |

### 비판적 이해

| 유형 | 발문 예시 | 필요한 장치 |
|---|---|---|
| 주장 파악 | 글쓴이의 주장으로 알맞은 것은? | — |
| 근거 평가 | 글쓴이가 든 근거로 알맞지 **않은** 것은? | — |
| 반론 | 글쓴이의 주장에 대한 반론으로 알맞은 것은? | — |
| 태도 파악 | 글쓴이의 태도로 알맞은 것은? | — |
| 조언하기 | `<보기>`의 친구에게 해 줄 조언으로 알맞은 것은? | `<보기>` |
| 관점 비교 | 이 글과 `<보기>`의 관점 차이로 알맞은 것은? | `<보기>` |
| 매체 비판 | 이 광고에서 과장된 표현은? | — |

## 한 차시를 구성할 때

지문 4개 · 문항 18개(초등 중학년 기준)를 만든다고 할 때 권장 배분이다.

**장치 기준**

| 장치 | 목표 비율 | 이유 |
|---|---|---|
| 밑줄 마크업(`㉠[밑줄:]`) 있는 지문 | 4개 중 **2~3개** | 어휘력 문항의 기본 장치 |
| 빈칸(`[빈칸]`) 있는 지문 | 4개 중 **1~2개** | 추론 문항에 효과적 |
| `<보기>` 상자 문항 | 전체의 **15~20%** (3~4문항) | 비판적·구조적 이해에서 변별력이 커짐 |

**발문 기준**

- 같은 발문 끝맺음("~알맞은 것은?")이 연속 3문항 이상 나오지 않게 한다
- 한 차시에 **부정형 발문**("~않는 것은?")을 1~2개 섞는다 — 꼼꼼히 읽는 습관을 만든다
- 지문 4개가 서로 다른 장르(설명문 / 이야기 / 주장하는 글 / 생활문)면 문항도 자연히 달라진다

---

## 자주 빠지는 함정

**1. 발문만 바꾸고 장치는 안 바꾼다**
"알맞은 것은?"을 "적절한 것은?"으로 바꿔도 학생 입장에서는 똑같은 문제다.
밑줄·빈칸·보기 상자 중 하나를 넣어야 실제로 다른 문항이 된다.

**2. `<보기>` 상자를 안 쓴다**
가장 확실하게 다른 문항을 만드는 장치인데 잘 쓰이지 않는다.
비판적 이해(조언·관점 비교)와 구조적 이해(문장 넣기)에서 특히 효과적이다.

**3. 부정형 발문이 없다**
"일치하지 않는 것은?"류가 하나도 없으면 학생이 대충 읽어도 답이 맞는 문제만 남는다.

**4. 정답 번호가 한쪽에 몰린다**
발문을 다양화해도 정답이 전부 ②번이면 찍어서 맞는다. 감사 스크립트가 경고를 낸다.

## 체크리스트

새 차시를 만든 뒤 확인한다.

- [ ] 같은 발문 끝맺음이 연속 3문항 이상 나오지 않는가
- [ ] 완전히 똑같은 발문이 두 번 쓰이지 않았는가
- [ ] `<보기>` 상자를 3문항 이상 썼는가
- [ ] 밑줄 마크업이 있는 지문이 2개 이상인가
- [ ] 빈칸이 있는 지문이 1개 이상인가
- [ ] 부정형 발문("~않는 것은?")이 1~2개 있는가
- [ ] 역량별 문항 수가 [question-format.md](./question-format.md)의 배분표와 맞는가
- [ ] `audit-assets.mjs`에서 상위 3개 패턴 비중이 50% 미만인가
